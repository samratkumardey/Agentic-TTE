# Reference protocols for the 12 core trials (E3)

These are the investigator-written target-trial protocols for E3 (eval/SCORING.md, Phase 3 changelog item 11b). Each one is used twice:
- **E3:** the agent's protocol is scored against it, element by element.
- **Attribution (item 11d):** it is substituted for the agent's protocol and compiled. So it must be a complete, valid protocol in our schema (`agentic_tte/protocol/models.py`, `TargetTrialProtocol`).

## Rules

1. **Write each reference before you open any model draft** of that trial (`runs/exit-H100-core/`). The templates come from the registry record only.
2. **Work from the trial's primary paper** (and the registry). The `_registry` block in each template holds the arm interventions and the registry's detailed description. The parser hint there is not a reference: overrule it whenever it's wrong.
3. **Copy, don't edit:** copy `templates/<NCT>.json` to `<NCT>.<your initials>.json` (for example `NCT01448109.SKD.json`) and fill that copy. Leave the templates unchanged.
4. **Fill these:**
   - **Eligibility:** each clinical criterion's `atoms` (concepts with name and domain, plus value and temporal constraint where the criterion has one). Consent and similar items: set `category` to `administrative`; they need no atoms.
   - **Treatment strategies:**
     - `is_comparator` on every arm;
     - the treatment arm's `components` (each a concept with name and domain, for example `{"concept": {"name": "hydrocortisone", "domain": "Drug"}}`);
     - a `grace_period` when the trial's treatment starts within a window, for example "within 12 hours of randomization".
   - **Assignment:** `confounders`, the baseline variables you would adjust for (concepts with name and domain).
   - **Time zero:** `anchor_event` in plain words (for example "ICU admission with septic shock"), with `rationale`.
   - **Outcome:** the primary outcome's `horizon` (for example `{"amount": 90, "unit": "day"}`), and `end_event` / `end_rule` if the trial has them ("28 days or discharge").
   - **Causal contrast:** `causal_contrast`, with `causal_contrast_evidence` (a quote from the paper) when it is stated.
5. **Check as you go,** from the repository root:

   ```bash
   uv run python eval/make_reference_templates.py --check eval/reference_protocols/NCT01448109.SKD.json
   ```

   It lists what is still missing and prints `complete` when the protocol is valid and has every element.
6. **A clinician** adjudicates only the items you mark uncertain (write them in the criterion's `notes`), plus a random 20% audit. Record the audit in `audit.md` in this folder. These references are reported as *investigator-written with clinician audit*, never as clinician gold.

## Files

- `templates/`: generated by `eval/make_reference_templates.py` from the cached registry records (public data). Regenerate them only if the selection changes, and note it in the SCORING.md changelog.
- `<NCT>.<initials>.json`: the filled references.
